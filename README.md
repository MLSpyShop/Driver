# Driver

Driver is a tool for deleting duplicate files and printing your Google Drive tree.

## Official Links
- Official GitHub Page: https://mlspyshop.github.io/Driver/
- GitHub Repository: https://github.com/MLSpyShop/Driver

## Overview
This project helps users identify duplicate files and inspect the structure of their Google Drive content in a simple, readable format.

## Features
- Detect duplicate files
- Print a tree view of your Google Drive structure
- Streamline cleanup of redundant content
